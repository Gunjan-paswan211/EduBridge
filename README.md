## 📚 EduBridge — Project Description

**EduBridge** is a modern, student-focused educational platform designed to make learning more **organized, interactive, and effective**. It brings essential study tools such as learning resources, quizzes, study planning, and progress tracking together in one place. 

### 🎯 Problem Statement

Students often face problems such as:

* Scattered study materials
* Poor study planning
* Difficulty maintaining consistency
* Lack of regular practice
* Difficulty identifying weak topics
* No simple way to track academic progress

EduBridge addresses these problems by combining **learning resources, quizzes, a study planner, and progress tracking** into one platform. 

### 💡 Main Features

* 📊 **Student Dashboard** — Shows study goals, study streak, completed lessons, quiz scores, and overall progress. 
* 📖 **Learning Section** — Students can select subjects and continue their learning path. 
* 📅 **Smart Study Planner** — Students can add subjects, topics, dates, and study duration and mark tasks as completed. 
* 📝 **Interactive Quiz** — Provides questions, instant feedback, score calculation, and final results. 
* 📚 **Learning Resources** — Provides notes, videos, and practice materials with search functionality. 
* 🎯 **Weak Topic Detection** — Uses quiz performance to identify topics that need more practice. 
* 📈 **Progress Analytics** — Displays subject-wise progress, quiz performance, and weekly activity. 
* 🌙 **Dark Mode** — Provides a light/dark interface for a comfortable user experience.
* 💾 **Browser Storage** — User activities can be saved in the browser so the student can continue where they left off. 

### 🛠️ Technology Used

**Frontend:**

* HTML5
* CSS3
* JavaScript

The project is designed as a frontend application, with user data and activity handled directly in the browser. 

### 🌟 Project Objective

The main objective of **EduBridge** is to help students **learn smarter, study better, and achieve more** by providing a single platform where they can organize their studies, practice concepts, identify weak areas, and monitor their learning progress.

### 🏆 Short Hackathon Description

> **EduBridge is an all-in-one educational platform that helps students organize their learning, plan their studies, practice through interactive quizzes, identify weak topics, and track their academic progress — all in one simple and user-friendly platform.**
